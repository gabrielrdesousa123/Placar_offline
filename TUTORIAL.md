# 📖 Tutorial: Como baixar e usar o Placar Bocha Offline

> **Tempo estimado:** 2 minutos  
> **Nível:** Iniciante (não precisa saber nada de programação)  
> **O que você precisa:** um computador com internet e um navegador (Chrome, Edge, Firefox ou Safari)

---

## 🎯 Objetivo

Baixar **1 único arquivo** no seu computador e abrir o placar sem precisar de internet, servidor ou instalação.

---

## 📥 Passo 1 — Abrir o repositório

1. Abra seu navegador (Chrome, Edge, Firefox ou Safari)
2. Vá para o endereço:  
   👉 **https://github.com/gabrielrdesousa123/Placar_offline**
3. Você verá uma página com a lista de arquivos do projeto

---

## 📁 Passo 2 — Localizar o arquivo do placar

Na lista de arquivos, procure por este arquivo:

```
📄 index.html
```

É o **único arquivo** que você precisa. Clique nele.

---

## 💾 Passo 3 — Baixar o arquivo

Você verá uma tela com o código do arquivo. Siga estes passos:

1. No canto superior direito da tela, procure um botão chamado **"Raw"** (ou "Bruto")
2. Clique em **"Raw"** — uma página branca com o código vai abrir
3. Agora aperte **Ctrl + S** (Windows) ou **Cmd + S** (Mac)
4. Escolha uma pasta no seu computador (por exemplo, **Downloads** ou **Área de Trabalho**)
5. Salve com o nome: **`index.html`**
   - ⚠️ **IMPORTANTE:** verifique se o nome é `index.html` e **NÃO** `index.html.txt`
   - No Windows: desmarque a opção "Salvar como tipo: Documento de texto"
   - Selecione "Todos os arquivos" na caixa de tipo

---

## ▶️ Passo 4 — Abrir o placar

1. Vá até a pasta onde você salvou o arquivo
2. Dê **duplo clique** no arquivo `index.html`
3. O placar vai abrir no seu navegador — **pronto!**

> 💡 **Dica:** você pode criar um atalho na área de trabalho para abrir com mais facilidade:
> - Clique com o botão direito no arquivo `index.html`
> - Selecione **"Criar atalho"**
> - Arraste o atalho para a área de trabalho

---

## 🎮 Como usar o placar

### Tela inicial (Configuração)
1. **Selecione o idioma** no topo: 🇧🇷 PT | 🇺🇸 EN | 🇪🇸 ES
2. **Escolha a classe**: BC1, BC2, BC3, BC4, Pares, Equipe ou Custom
3. **Preencha os nomes** (opcional — se deixar em branco, aparece "VERMELHO" e "AZUL")
4. **Preencha os clubes** (opcional)
5. Clique em **▶ INICIAR PARTIDA**

### Durante a partida
- **▶** ao lado de cada timer: inicia/pausa o tempo daquele atleta
- **Clique no número do placar**: adiciona +1 ponto
- **− e +**: controla quantas bolas foram jogadas
- **⚠️ Adicionar Violação**: registra infrações conforme as regras oficiais
- **PRÓXIMO END ▶**: avança para a próxima parcial

### Ao final da partida
- Clique em **☰** (menu no canto superior esquerdo)
- Selecione **📄 Ver Súmula**
- Clique em **🖨️ Imprimir / Salvar PDF** para gerar a súmula oficial

### Telão para TV/Projetor
- Clique em **☰** → **📺 Telão / Scoreboard**
- Uma nova aba abre com o placar ampliado
- Atualiza automaticamente a cada 2 segundos

## ❓ Perguntas frequentes

### "Apareceu um alerta pedindo nome dos atletas"
Isso acontece quando o navegador está com uma versão antiga em **cache**. Para resolver:
- Feche a aba do placar
- Abra uma **aba anônima** (Ctrl + Shift + N no Chrome/Edge, Ctrl + Shift + P no Firefox)
- Abra o arquivo `index.html` novamente
- Ou limpe o cache: Ctrl + Shift + Delete → "Imagens e arquivos em cache"

### "O nome do arquivo virou index.html.txt"
O Windows adicionou `.txt` automaticamente. Para corrigir:
1. Abra o Explorador de Arquivos
2. Clique em **Exibir** → marque **"Extensões de nomes de arquivos"**
3. Clique com botão direito no arquivo → **Renomear**
4. Remova o `.txt` do final, deixando apenas `index.html`
5. Confirme quando o Windows perguntar

### "Funciona no celular?"
Sim! Basta enviar o arquivo `index.html` para o celular (WhatsApp, e-mail, etc.) e abrir com o navegador. Funciona em Android e iPhone.

### "Precisa de internet depois de baixar?"
**Não.** O arquivo funciona 100% offline. Você pode até desconectar o Wi-Fi depois de baixar.

### "Meus dados ficam salvos?"
Sim, no próprio navegador. Se você fechar e reabrir o placar, a partida continua de onde parou. Para começar um jogo novo: **☰ Menu → Zerar Jogo Completo**.

### "Posso usar em competições oficiais?"
Sim. O layout e as regras são idênticos aos do SCBP, sistema usado em competições brasileiras de Bocha Paralímpica.
